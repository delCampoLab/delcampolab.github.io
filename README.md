# delcampolab.com

Website of the [del Campo Lab](https://delcampolab.com/) — Microbial Ecology and
Evolution, Institut de Biologia Evolutiva (CSIC-UPF), Barcelona.

Built with [Hugo](https://gohugo.io/) (extended 0.135.0) and the Hugo Blox
Builder research-group theme. Pushing to `main` deploys to GitHub Pages via
GitHub Actions.

- Local preview: `hugo server --port 1313 --disableFastRender`
- Repo mechanics, content layout, and the publications workflow are documented
  in [CLAUDE.md](CLAUDE.md)
